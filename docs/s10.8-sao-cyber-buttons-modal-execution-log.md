## Research Notes

- DEV Cyberpunk button reference: use clipped polygon plate, offset shadow plate, duplicated hidden glitch text, small tag, and hover-only glitch layer.
  Source: https://dev.to/jh3y/css-cyberpunk-2077-buttons-taking-your-css-to-night-city-43l0
- MDN `clip-path`: polygon clipping is appropriate for non-rectangular UI plate shapes.
  Source: https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Masking/Clipping
- MDN CSS animation performance: favor transform/opacity for interactive animation.
  Source: https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Performance/CSS
- MDN `prefers-reduced-motion`: user motion preference must disable or reduce non-essential effects.
  Source: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion
- WAI-ARIA APG menu button / dialog modal: dropdown menus and destructive confirmations must preserve keyboard and focus semantics.
  Sources:
  - https://w3c.github.io/wai-website/ARIA/apg/patterns/menu-button/
  - https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/
- MDN `<dialog>`: keep native login modal behavior through `showModal()` and styled backdrop.
  Source: https://developer.mozilla.org/en-US/docs/Web/HTML/Element/dialog
- WarrenUhrich/SAO-UI: reference only for SAO system-message / translucent modal feel, not copied.
  Source: https://github.com/WarrenUhrich/SAO-UI
