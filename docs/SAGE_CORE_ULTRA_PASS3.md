# SAGE CORE Ultra Pass 3（使用者規格 2026-06-11b，原文=桌面 2026611提示詞.txt 第二版）

> 只做 Ultra 桌機版（不做降級、不犧牲桌機）。架構保留未來可拆分。修正令優先序：首屏防閃 → Ultra VFX → 3D 軌道 → 後製 → 背景霧 → 全站 UI 統一 → 模型鈕 → 流程測試。

## 必修問題清單
首屏閃普通背景／法陣偏平面／軌道像單條線／後製把對比洗掉／背景霧未融合主站／全站 UI 未統一／模型選擇鈕要正式修好。

## 一 首屏防閃（最優先）
- 最早 CSS 即有 critical background（深黑+暗金+微青綠霧；禁白底/普通漸層/舊背景）。
- boot veil：全螢幕、立即顯示（深黑底+微暗金霧+低亮中心核+極淡外圈輪廓；禁空白/純黑/白屏）。
- VFX canvas 初始 opacity:0；renderer/DPR/scene/composer/shader/resize+**至少 render 一幀**完成才加 vfx-ready、canvas 300-600ms 淡入。
- UI 順序：veil → canvas 第一幀 ready → canvas 淡入 → 登入卡淡入 → veil 淡出。
- WebGL 失敗 → Ultra 靜態 fallback（深黑暗金+靜態低亮法陣+暗褐霧），console 記錄、UI 不顯粗糙錯誤。
- 禁：白屏/未套樣式卡/字體大跳動/canvas 黑屏閃/先卡片後背景。

## 三 軌道=軌道系統（非單線），每條至少含
主帶(有寬度發光玻璃帶,外緣亮內緣暗)/內緣細金線/外緣白金或青綠線/簇狀刻度(跟透視變形)/3-9 節點(小光球+暈+微環)/沿軌碎片/節點短拖尾(沿切線)/前半亮後半被霧吃/各軌不同傾角深度速度方向/穿過法陣・卡片・霧有遮擋。
五型：A 主黃金(琥珀,傾12°,中快)/B 青綠索引(-24°,慢)/C 白金封印(近內圈,精準中速)/D 暗金遠景(32°或-36°,慢,被霧遮)/E 斷裂資料(短弧+節點+碎符,快,分群)。

## 四 環距拉大（半徑表）
奇點0-.08｜能量球.09-.18｜封印.22-.36｜內符文.42-.52｜主法陣.64-.86｜資料流.98-1.18｜3D軌道1.05-1.45｜外索引結界1.36-1.68｜遠景霧碎片1.70+。
核心區留尊貴空間；環間能看到霧/粒子/光穿過；近景清楚遠景略糊；外圈碎片分群落；卡片背後局部降噪。

## 五 轉速加快但分層
核心=低頻呼吸不轉｜封印×1.25-1.5｜內符文×1.8-2.3｜主骨架×1.2｜中圈資料流×2.2-3.0（主動態來源）｜斷裂軌道×2.5 分群｜青綠×1.1-1.3｜節點沿軌行、近前景更快感。點火 0.8s 全體×1.6-2.2 後回演算速。禁全同向/全同速/全同步閃/風扇轉/快到看不清。

## 六 3D 景深
滑鼠 parallax（前中遠不同位移、克制）｜傾斜軌道帶 3-5 條｜軌道星體節點（近大亮拖尾明顯、遠小暗被霧遮）｜DOF 概念（前景粒子糊+遠景霧糊、中景清楚）｜霧三層(暗褐/暗金/青綠)遮遠景｜卡片後方壓暗、前景少量粒子可過卡但不擋字｜細量體積光(不可粗白)｜核心微熱浪折射(不影響文字)。

## 七 後製保對比
threshold 提高(只有核心/節點/主星芒強 bloom)｜全域 strength 降、半徑小｜contrast pass 保暗部｜exposure 降過曝｜金=琥珀+白金不可灰黃、青綠退後不可螢光｜grain 細微｜CA 極輕｜vignette 不死黑｜中景與 UI 文字清楚。
順序：Render→(selective bloom 概念)→DOF 概念→light shafts→subtle distortion→grain→極輕 CA→vignette→tone/contrast→Output。

## 八 背景霧（取 poc 優點）
厚度非平面灰霧/暗部有細節/暗褐=手稿、暗金=神聖、青綠=索引/慢流動/遮遠景軌道/不降文字可讀性/霧與星點分離。減少：均勻星點、太空感、無方向散點、大面積藍黑空洞。增加：羊皮紙纖維/墨跡灰塵/燒焦紙屑/文字殘影/暗金資料煙/卷宗框殘影。

## 九 全站 UI 統一（Sage Core 風格）
黑金玻璃/細金框/暗金材質噪/微節點燈/小刻度/原創英文 HUD/繁中主內容/白金高亮/琥珀主色/青綠資料輔色/橘紅僅錯誤。
登入頁 VFX 60-80%、卡片=法陣投影控制台；工作區 VFX 退 20-35%、輸入結果為主角、分析中才點火。
登入卡：四角鎖扣+內框刻度+微節點燈+暗金材質+系統銘牌+背後降噪+柔背光。
Google 鈕=AUTHORIZATION GATE 授權閘門（保 G、金細框、暗金玻璃、右側狀態燈、hover 內圈封印微亮、click 四向鎖扣亮、成功核心點火）。訪客鈕同風格較低層級。

## 十 模型選擇鈕（必修）=MODEL CORE SLOT 模型核心槽
檢查：選中可辨/hover/active/focus-visible/disabled/loading 明顯；dropdown 不被 z-index/overflow 裁切且最上層；桌機手機可點；名稱不截斷；切換正確更新 model value；API 用對模型；失敗有提示；風格一致。
外觀：暗金玻璃底+細金框+左側核心節點+右側微型三角 HUD；選中白金/琥珀高亮；hover 邊框金光流動；focus 白金外環；disabled 降透明仍可讀。
Dropdown：浮空黑金面板、z 最高、不被裁切；每選項小節點；選中亮點+細框；hover 暗金掃描線；切換顯示 MODEL SYNC/模型核心同步；失敗 MODEL LINK FAILED 橘紅短提示（禁 alert）。
互動：更新 UI+內部 model value；不破壞 API/預設/使用者選擇/state。

## 十二 動效狀態規格（摘）
boot=veil+低亮核呼吸→第一幀後 canvas 淡入→卡片晚一點→veil 淡出。待機=全層低亮慢動。G hover=框微亮+金光流邊+核心+10-15%。G click=四向鎖序亮+核心短點火+資料線吸入。登入成功=核心白金短亮+中圈內→外展開+軌道節點加速一圈+轉場工作區模式。工作區待機=法陣降亮。模型 hover=槽框微亮+節點脈衝+背景局部壓暗。切換=節點短亮+MODEL SYNC。分析開始=核心短亮+粒子由輸入區流向核心+讀取條 loading。分析中=法陣 50-65%。完成=核心短亮+資料流輸出到結果區+邊框微亮+回落。失敗=橘紅短閃+軌道錯位 ≤0.8s。

## 嚴格限制
不動 Firebase Auth/Google 登入/訪客/API/模型值傳遞/歷史/草稿/分析流程；禁 PNG 法陣、動漫元素；繁中主內容；英文 HUD=原創。

## 驗收
首屏無閃無白屏無未套樣式；軌道=有寬度節點刻度拖尾遮擋的 3D 系統；環距大、轉速有感；後製不灰不糊不洗對比；全站 UI 統一；模型鈕可用且高級；登入/切模/分析全流程不破。
